## 1. 研究动机与背景

化工安全事故具有"小概率、大后果"的特征——单起事故可能导致数百人伤亡和数亿元损失。然而，事故调查报告分散在政府网站、行业数据库和学术文献中，以非结构化文本形式存在，难以被系统性地查询和分析。

传统的事故分析方法依赖人工阅读报告、手动归纳模式，效率低下且难以扩展到大规模数据。大型语言模型（LLM）虽然在文本理解和生成方面展现出强大能力，但在专业领域中存在幻觉问题——模型可能编造不存在的事故原因或混淆不同事故的细节。

本项目的核心动机是：**能否利用 LLM 自动从海量非结构化事故报告中构建结构化知识图谱，再用图谱中的因果约束来回答安全问题，同时控制幻觉？**

## 2. 问题定义与挑战

### 核心问题

1. **自动化 KG 构建**：如何从 1,300+ 份非结构化中文化工事故报告中，自动抽取实体、关系与因果链？
2. **因果约束问答**：如何在回答安全问题时，确保每个陈述都能追溯到知识图谱中的因果路径，从而控制幻觉？
3. **多源数据融合**：如何将事故报告、化学品物性、气象数据等多个异构数据源整合为统一的分析视图？

### 关键挑战

- **中文事故文本的特殊性**：化工事故报告使用大量专业术语和长句描述，实体边界模糊
- **因果链完整性**：单起事故的因果链可能涉及 5–10 步，LLM 容易遗漏中间环节或添加推测
- **幻觉控制**：纯 LLM 回答专业安全问题时平均产生 13.2 个不在知识图谱中的实体
- **数据源碎片化**：事故数据分散在多个政府网站和公众号中，格式各异

## 5. 实验分析

### 5.1 数据规模

| 指标 | 数值 |
|------|------|
| 知识图谱节点 | 6,976（Abnormal 3,570 / Accident 1,579 / Equipment 688 / Consequence 641 / Material 427 / Mitigation 71） |
| 因果关系边 | 23,111 |
| SQLite 事故记录 | 1,579（100%含根原因与后果，79%含日期） |
| 化学品物性 | 29 种 |
| 时间跨度 | 1947–2026（79 年） |

### 5.2 对照实验：Graph RAG vs 关键词RAG vs 纯LLM

20 组问题覆盖 7 种因果模式，三组 baseline 同时对比。核心结果：

| 指标 | 关键词RAG | Graph RAG | 纯LLM |
|------|----------|-----------|--------|
| 无幻觉率 | 40% | **70%** | 5% |
| 来源可追溯率 | 100% | 55% | 0% |
| 诚实拒答率 | 10% | **55%** | 0% |
| 平均幻觉实体数 | 1.2 | **0.65** | 5.95 |

### 5.3 幻觉检测方法

从 Neo4j 导出完整实体名白名单，结合化工安全领域特征词正则提取回答中的候选实体，逐一比对白名单。不在 KG 中的实体标记为幻觉。

### 5.4 数据洞察

事故类型：爆炸占 61.2%，中毒窒息 26.9%，火灾 5.1%。时间趋势：2010 年代为高峰（616 起），2020 年代显著下降。化学品频次 Top 3：硫化氢 49 起、氮气 43 起、甲醇 39 起。设备频次 Top 1：反应釜 62 起。最危险异常状态："形成爆炸性混合气体"关联 102 个后果节点。因果链以 2-3 步级联为主，最深可达 6 步。

## 8. 项目总结

ChemSafe-KG 构建了首个大规模结构化中文化工安全事故知识图谱。通过 LLM 驱动的 Prompt Chain 策略，从 1,579 份非结构化报告中自动抽取了 6,976 个实体和 23,111 条因果关系，并实现了基于因果路径约束的 Graph RAG 问答系统。

对照实验证明：相比纯 LLM，Graph RAG 将幻觉实体数减少 9 倍（0.65 vs 5.95），来源可追溯率达 55%（纯 LLM 为 0%），并且在知识图谱覆盖范围外的问题上诚实拒答率 55%（纯 LLM 为 0%）。

本项目验证了"用 LLM 建 KG，再用 KG 约束 LLM"这一闭环方法在化工安全领域的可行性和有效性。
