## 常见问题准备

### Q: 为什么选择 Neo4j 而非纯关系数据库？
A: 事故因果链天然是图结构 (设备→异常→后果)，关系数据库需要多次 JOIN 才能获取多跳路径，而 Neo4j 的 Cypher 可变长路径查询 `[:leads_to*1..3]` 一条语句即可完成。

### Q: LLM 抽取质量如何保证？
A: 三层保障: ① Prompt Chain 严格约束实体/关系类型 ② JSON Schema 强制结构化输出 ③ ResultValidator 自动校验 + 非法类型过滤。

### Q: 如何避免 LLM 幻觉？
A: Graph RAG 架构: LLM 被严格约束在检索到的因果路径内生成答案，不得添加路径外内容。系统 Prompt 明确要求"如果路径不相关，直接回答无法回答"。实测中 LLM 能正确识别不相关问题并拒绝编造。

### Q: 系统能否处理英文事故报告？
A: CSB (美国化学品安全委员会) 数据源已预留接口，爬虫可解析调查卡片。提取逻辑与中文一致，只需调整分词策略。

### Q: 可扩展性？
A: pipeline.py 支持分阶段执行 + 断点续跑。新增数据源只需在 ReportCrawler.CRAWL_SOURCES 添加 URL 和解析器。
